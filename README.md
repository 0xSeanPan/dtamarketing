# 智能体营销研究（Agent Marketing Research）

> 创建：2026-08-16 ｜ 当前阶段：Phase 0（框架搭建与基线测量） ｜ 性质：长期滚动的研究知识库（中英双语） ｜ 阅读入口：`wiki/index.html`（右上语言按钮可切换中文 / English）

## 项目使命

系统研究"面向 AI 智能体的营销"这一新学科，把研究成果沉淀为三类可复用资产，用于指导业务投入与放弃：

- **业务取舍**——判断哪些机会值得投入、哪些应主动放弃（见 `03-商业化/业务机会矩阵.md`）
- **技能储备**——明确需要提前构建的能力与优先级（见 `03-商业化/技能储备地图.md`）
- **商业化路径**——把研究转化为可变现的服务、产品或内容资产

## 核心命题

人是注意力经济的产物——决策被信息流、搜索排名、情绪与品牌联想塑造；AI 智能体不是——它基于检索、评分与委托人的目标函数做出代理决策。营销对象正从"人的注意力"迁移到"智能体的决策链"。如何被智能体**识别、发现、采用、复购**，是注意力经济之后的新营销问题。完整论证见 `01-总纲/研究框架.md`。

## 工作流（每次研究会话从这里进入）

1. 读 `00-管理/研究路线图.md`，确认当前阶段与优先模块
2. 打开对应模块文档，按"研究问题 → 方法 → 证据 → 结论 → 下一步"推进
3. 新发现同步两处：模块文档的"当前结论"区 + `00-管理/研究日志.md` 追加一行
4. 结论足以影响业务判断时，更新 `03-商业化/` 两个文档，必要时在 `00-管理/业务决策看板.md` 立项评审
5. Markdown 落盘后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File build_wiki.ps1` 重建 WIKI（月度自动化会自动执行这一步）

## 双层结构与同步机制

本项目是"真相层 + 阅读层"的动态系统：

- **真相层**：本目录的 Markdown 文档集，唯一事实来源，由 AI 协助持续研究、更新与演进
- **阅读层**：`wiki/index.html`——面向人类阅读的单文件双语 WIKI（侧边导航、全文搜索、SVG 图解、中英切换），由 `build_wiki.ps1` 从真相层自动生成

同步规则：

- 每次修改 Markdown 后运行构建命令，WIKI 即与文档集完全一致；禁止手改 `wiki/index.html`，发现不同步时重新构建即可
- 新增 Markdown 文档须在 `build_wiki.ps1` 的 `$pages` 配置中登记（中英成对），才会进入 WIKI
- **双语同步**：中文文档为第一事实来源；修改中文结论时同步修订 `en/` 对应英文镜像（术语对照依据见 `01-总纲/研究框架.md` 术语表与 `en/01-framework/research-framework.md` 的 Terminology Notes）。英文版用词遵循学界/业界既有规范（GEO、citation share、agentic commerce 等），不生造直译
- 全部脚本、配置与生成物的登记和运维说明见根目录 `数字化开发管理.md`（面向系统阅读，不在 WIKI 中呈现）
- 每月 1 日自动化任务执行 `00-管理/月度推进流程.md` 全流程：情报扫描 → 去噪 → 研究推进 → 落盘更新 → 重建 WIKI（触发方式待定，SOP 已就绪）

## 维护规则

- 单一事实来源：一个结论只在它的归属文档里维护，其他位置以链接引用，不复制正文
- 所有结论必须带标记：`[日期][证据等级 A/B/C] 来源`，等级定义见 `05-方法/研究方法与模板.md`
- 文档只保留当前有效内容：过时结论直接改写或删除，不保留"更新历史"段落；时间线索进研究日志
- 对外交付的正式调研报告按用户规范输出 PDF；本知识库维持 Markdown 活文档形态，不做冗余排版
