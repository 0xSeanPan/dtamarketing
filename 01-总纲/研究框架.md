# 研究框架：从注意力经济到智能体经济

> 最后更新：2026-08-16 ｜ 状态：v1.0（Phase 0 产出，重大范式变化时修订）

## 1. 核心命题

人的购买决策受注意力分配机制塑造：信息流按停留时长分发、搜索按点击行为排序、品牌靠重复曝光建立联想。这三十年发展出的营销学，本质是"对人类注意力与情绪的系统干预"。

AI 智能体改变了这个前提。当用户把"找产品、比价格、下订单"委托给智能体：

- 信息获取从"被推送"变为"主动检索 + 工具调用"，曝光量不再直接等于心智份额
- 决策依据从情绪与品牌联想，变为语料中的事实、结构化数据、评分与履约记录
- 说服对象分成两层：设定目标函数的委托人（人或组织），以及执行决策的模型

因此"智能体营销"不是渠道优化的延续，而是营销对象的切换：从经营"人的注意力资产"转向经营"模型决策链中的可被发现性与可被信任性"。

## 2. 范式对比

| 维度 | 注意力经济（说服人） | 智能体经济（说服代理决策链） |
|---|---|---|
| 决策者 | 人脑：有限理性、情绪驱动 | 模型 + 委托人目标函数 |
| 信息获取 | 信息流推送、搜索排名 | RAG 检索、工具调用、协议化目录 |
| 影响机制 | 重复曝光、故事、情绪、社交证明 | 事实语料、结构化可读性、评分、履约记录 |
| 内容偏好 | 简单、视觉冲击、情绪共鸣 | 准确、可分块抽取、含数据与出处 |
| 主要渠道 | 信息流、搜索、社交媒体 | AI 搜索答案、agent 爬虫、MCP 目录、协议化商品目录 |
| 转化路径 | 点击 → 落地页 → 话术转化 | 被引用 / 被调用 → 协议化下单与结算 |
| 忠诚来源 | 品牌信任、习惯 | 履约质量、SLA、价格稳定、交易记录 |
| 核心指标 | 曝光、CTR、ROI | 识别准确率、引用份额、调用量、重复调用率 |

关键推论：传统营销里"模糊但动人"的优势（品牌故事、情绪价值）在代理决策链中权重下降；"精确且可验证"的资产（结构化产品数据、第三方事实语料、履约记录）权重上升。但委托人仍是人，品牌并未消亡，它退守到"委托人设定目标与白名单"的那一层。

## 3. 代理链条

```
终端用户（意图与预算）
    │  委托：目标函数 + 约束条件
    ▼
用户智能体（检索 → 评估 → 选择 → 执行）
    │  依赖：训练语料 / RAG 检索源 / 工具目录 / 协议网络 / 历史履约记忆
    ▼
你的产品（被识别 → 被发现 → 被采用 → 被复购）
```

营销动作因此分布在三个战场：

1. **语料层**——模型对世界的"先验认知"来自训练与检索语料，你在这层建立事实存在感
2. **决策层**——agent 在候选集中做选择时依据的信号：结构化数据、评分、价格、可调用性
3. **协议层**——交易与信任的标准化：商品目录、下单、结算、身份认证（ACP / UCP / x402 等）

## 4. 智能体营销漏斗（研究主线）

| 层 | 定义 | 核心问题 | 关键词 |
|---|---|---|---|
| M1 被识别 | agent 及其模型能准确理解你的实体、能力、价格、约束 | 模型"眼里"的你和真实的你差多少 | 机器可读性、结构化数据、llms.txt、实体消歧 |
| M2 被发现 | 用户经 agent 检索时，你进入候选集与最终答案 | 你的引用份额由什么决定 | GEO、AEO、AI 搜索、agent 爬虫、引用份额 |
| M3 被采用 | agent 把你推荐给用户，或直接调用你的工具完成事务 | agent 的选择函数里有哪些变量 | MCP、工具调用、API 产品化、协议化目录 |
| M4 被复购 | agent（及其委托人）与你形成持续交易关系 | 机器忠诚度由什么构成 | ACP、UCP、x402、履约记录、信任评分 |

四层的依赖关系是单向的：识别错误则发现无意义（agent 引用了一个不存在的能力），发现缺失则无采用机会，采用不达标则无复购。因此研究顺序与基线测量都按 M1 → M4 展开。

## 5. 术语表

| 术语 | 含义 |
|---|---|
| GEO | Generative Engine Optimization，面向生成式引擎（AI 搜索、AI 摘要）的优化，目标是被引用而非被排名 |
| AEO | Answer Engine Optimization，面向答案引擎（语音助手、问答型 AI）的优化，GEO 的近义词，边界日益模糊 |
| 引用份额 / Share of Model | 在一组标准化提问下，某实体被 AI 答案提及或引用的比例，对应传统营销的"市场份额" |
| Agent 爬虫 | 代表模型或 AI 平台抓取网页的机器人，如 GPTBot、ClaudeBot、PerplexityBot、Google-Extended |
| llms.txt | 站点向 LLM 提供内容摘要的约定文件（llmstxt.org 提出），行业采用度存在争议，见 M1 |
| MCP | Model Context Protocol，Anthropic 发起的智能体工具接入协议，已成主流工具生态标准之一 |
| A2A | Agent2Agent，agent 之间互相发现与协作的协议方向 |
| ACP | Agentic Commerce Protocol，OpenAI 与 Stripe 主导的智能体商务协议，覆盖发现—下单—支付，已在 ChatGPT 生产环境运行 [2026-08][A] Stripe 官方博客（stripe.com/blog/10-lessons） |
| UCP | Universal Commerce Protocol，Google 与 Shopify 主导的商务协议，2026 年 1 月进入生产 [2026-08][B] 第三方技术文档，官方主页待核实 |
| x402 | Coinbase 推出的智能体原生支付协议，基于 HTTP 402 状态码 |
| 机器忠诚度 | agent 重复选择同一供应商的现象，由履约质量、价格稳定、信任评分与组织记忆驱动 |

## 6. 研究假设（可证伪，逐条验证后升级为结论或淘汰）

- H1：结构化、含数据与出处的内容，被 AI 引用的概率显著高于传统营销文案。背景：Princeton 等机构 2024 年 GEO 论文（GEO-Bench，10,000 查询 × 25 领域）显示引用、引文、统计数据可提升可见性，关键词堆砌是最差策略 [2026-08][B]
- H2：MCP 工具的名称与描述质量显著影响被调用率（待设计实验）
- H3：AI 搜索的引用源高度集中于少数高权重知识与社区站点（Wikipedia、Reddit、GitHub、垂直权威站），进入这些源的杠杆效率高于自有站点优化（待验证）
- H4：agent 渠道的转化决策对"价格透明 + 履约确定 + 结构化可比"的敏感度远高于品牌与视觉设计（待验证）
- H5：主流平台正在形成 agent 原生的应用目录与商品目录（MCP 目录、ChatGPT 内电商、Google AI Mode），先进入者享有分发红利窗口，窗口期约 12–24 个月（待验证）
- H6：Google 官方声明 AI Overviews 没有特殊的标记文件或 schema 可以解锁，被引用靠内容质量与权威度 [2026-08][B] Google 搜索文档（待在 M2 复核原文）

## 7. 研究边界

**在范围内**：所有"信息获取或交易经智能体完成"的 B2C 与 B2B 场景；营销动作在语料层、决策层、协议层的分布；对个人业务取舍、技能投资、商业化的推导。

**范围外**：agent 内部技术实现细节（仅研究到影响营销决策的深度）；通用 LLM 技术评测；与智能体渠道无关的传统增长手法。
