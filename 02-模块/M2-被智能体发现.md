# M2 被智能体发现（Discovery）

> 状态：协议冻结（`面板测试问题集.md` v1.0），首轮基线待执行 ｜ 最后更新：2026-09-01 ｜ 总纲：`../01-总纲/研究框架.md`

## 1. 定义

当用户通过智能体检索信息时，目标实体进入 agent 的候选集并出现在最终答案里。发现对应传统营销的 SEO/SEM，但分配机制不同：搜索给的是排名与点击，AI 答案给的是提及与引用——答案往往直接消解查询，没有点击可以依赖。

领域现状：该领域已有学术框架。2024 年 Princeton、Georgia Tech、Allen Institute、IIT Delhi 团队发表 GEO 论文并发布 GEO-Bench（10,000 查询 × 25 领域）[2026-08][B]；2026 年出现"引用选择 → 引用吸收"两阶段测量框架，区分"被列为来源"与"内容实际进入答案"两个层次 [2026-08][B] arxiv 2604.25707。方法学新增三件（2026-09 扫描）：可见性测量需重复采样与置信区间而非单次点估计（arxiv 2603.08924 [A]）；GEO 排名操纵的统一基准（arxiv 2605.29107 [A]，黑盒内容重写效果可匹配梯度攻击）；GEO 系统综述确立"提及 / 引用 / 吸收"三层指标层级（arxiv 2607.14035 [A]）。本模块直接站在这些工作之上，重点做中文场景与自有品类的实证。

## 2. 研究问题

- M2-RQ1：在目标品类的一组标准问题下，各 AI 平台（ChatGPT、Perplexity、Gemini、AI Overviews、豆包/元宝等中文入口）的引用份额如何分布？集中度多高？
- M2-RQ2：被引用的源有什么共性——域权威度、内容结构（可分块抽取）、含数据与出处、社区信号（Reddit/知乎/贴吧式讨论）、时效性？Google 声明无特殊标记可解锁 AI Overviews，靠内容质量 [2026-08][B]，需复核原文并检验
- M2-RQ3：agent 爬虫（GPTBot、ClaudeBot、PerplexityBot、Google-Extended）的抓取与 AI 引用的相关性如何？robots.txt 放行/屏蔽的取舍框架是什么？
- M2-RQ4：传统 SEO 排名与 AI 引用的相关性——高排名是否高引用？偏差案例（小站被引、大站被忽略）的成因？
- M2-RQ5：中文场景特有变量——中文语料生态、平台封闭内容（公众号、小红书）对 agent 的可见性、国产模型与国际模型的引用源差异？
- M2-RQ6：付费获取 agent 流量的通道（平台广告、赞助位、目录收录）现状与性价比？

## 3. 方法与实验协议（草案）

提示词面板测试：为目标品类构造 50–100 个真实购买意图问题（信息型 / 比较型 / 交易型分层），每月在固定平台集上执行，统计：提及率（答案是否提到实体）、引用份额（被引次数 / 全部引用）、引用域名分布、答案位置（首位推荐 / 混排 / 仅提及）。追踪方法参考 arxiv 2604.25707 的两阶段框架，把"被吸收进答案的语言与事实"单独计分。方差控制与稳定度报告按 arxiv 2603.08924 设计。执行细则已冻结于 `面板测试问题集.md`（品类：扫地机器人；60 问；统计口径与变更控制）。

爬虫日志分析：对自有或样本站点，按月统计 agent 爬虫请求量与 UA 分布，与面板测试结果做相关性对照。

## 4. 指标体系

| 指标 | 定义 | 采集方式 |
|---|---|---|
| 提及率 | 提到目标实体的问题占比 | 面板测试 |
| 引用份额 | 目标实体引用数 / 该问题全部引用数 | 面板测试 |
| 引用吸收率 | 被引后内容实质进入答案（语言、数据、结构被采用）的比例 | 两阶段评分 |
| 域名集中度 | Top10 被引域名占全部引用的比例 | 面板测试 |
| agent 爬虫流量 | 各 agent 爬虫请求数与增速 | 站点日志 |

## 5. 当前结论

- [2026-09][A] Adobe Analytics（覆盖 130+ 北美零售商、1T+ 次访问）：AI 引荐流量至美国零售站点 2026 Q1 同比 +393%；AI 访客转化率比非 AI 访客高 42%（2026-03 创纪录）——AI 渠道已从方向性趋势变为规模化事实
- [2026-09][B] Ahrefs：AI Overview 引用中仅 38% 来自 Google 自然结果前 10（2025 年中为 76%）；80% 的 LLM 引用不在 Google 前 100——SEO 排名与 AI 引用相关性持续走弱，M2-RQ4 首个量化锚点
- [2026-09][B] Goodie 面板（41 个 B2B 品牌站，2025.8–2026.5）：ChatGPT 占 B2B AI 引荐份额 89.1%→62.6%，Claude 1.4%→18.5%、Gemini 2.4%→10.6%、Perplexity 3.1%→7.3%——AI 引荐多引擎化，单平台优化策略折旧加速
- [2026-09][A] arxiv 2603.08924：AI 可见性单次运行点估计应视为样本估计量，重复采样 + 置信区间是最低方法学要求；页面内容变更可致引用份额显著波动——本模块面板协议已按此设计（方差抽样 6 问 × 3 次）
- [2026-09][A] arxiv 2604.25707（geo-citation-lab，602 提示词、21,143 条引用）：平台引用行为分化——Perplexity 与 Google 引用广度大，ChatGPT 引用少而平均影响力高——跨平台差异的可复现参照，中文面板结果将对照该梯度
