## 1. 目的与口径

按"官方协议与规范"监测清单逐月记录 ACP / UCP / x402 / MCP 及国内 AI 导购协议线的商家准入、类目扩张、结算规则、治理结构变化，形成协议时间线，支撑 M3-RQ3（协议化目录的准入与排序）、M4-RQ4（信任基础设施）与决策看板 D2/D3 的复审。

口径：
- 只记影响商家策略与研究判断的事件；事件必须带 `[日期][证据等级]`
- 同一事实多源报道取最早的一手源
- 已被新事件取代的口径：改写，不保留旧文（与项目文档维护规则一致）

## 4. 对研究判断的含义

1. **商家无需选边**：Visa Intelligent Commerce Connect（2026-04，[B]）提供跨 Visa TAP / Stripe MPP / OpenAI ACP 的多协议网关——协议互操作层出现，阵营对立让位于"任一协议接单均可触达"
2. **目录分发正规化**：Claude Marketplace 与 ChatGPT 插件目录（Shoppable、Snipp 等入列）说明"agent 应用目录"进入平台店态阶段——H5（目录红利窗口）观测支持增强
3. **准入受控化**：UCP 审批制 + ACS 目录（Shopify 首选）说明协议接入正从开放集成转向平台审核——先申请先占位，D3 复审时点（2026-10）证据已足
4. **信任基础设施缺口**：x402 规模化但身份验证缺失（Cloudflare Wallets 冒用争议）——M4-RQ4 研究窗口打开
