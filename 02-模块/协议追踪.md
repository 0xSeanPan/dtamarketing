## 1. 目的与口径

按"官方协议与规范"监测清单逐月记录 ACP / UCP / x402 / MCP 及国内 AI 导购协议线的商家准入、类目扩张、结算规则、治理结构变化，形成协议时间线，支撑 M3-RQ3（协议化目录的准入与排序）、M4-RQ4（信任基础设施）与决策看板 D2/D3 的复审。

口径：
- 只记影响商家策略与研究判断的事件；事件必须带 `[日期][证据等级]`
- 同一事实多源报道取最早的一手源
- 已被新事件取代的口径：改写，不保留旧文（与项目文档维护规则一致）

## 4. 对研究判断的含义

1. **商家无需选边**：Visa Intelligent Commerce Connect（2026-04，[B]）提供跨 Visa TAP / Stripe MPP / OpenAI ACP 的多协议网关；ACP 又将 Meta 纳入创建方——阵营对立进一步让位于"任一协议接单均可触达"，单一 ACS 集成即可覆盖 ChatGPT / Meta 系 / Google
2. **目录分发正规化并带审核**：Claude Marketplace 2,000+ 条目、插件提交即安全扫描，ChatGPT 插件目录（Shoppable、Snipp 等入列）——agent 应用目录进入"有审核、有结算、有服务商"的平台店态，H5（目录红利窗口）观测支持增强
3. **准入从审批制转向自助集成**：UCP Merchant Center hub 在美开放三能力，ACS 以 Shopify 为目录首选——准入摩擦下降，但区域节奏（美→澳加 2027）成为新门槛；D3 复审结论需按"区域分批"改写，不再是"先申请先占位"的单点判断
4. **付费占位成为新变量**：ChatGPT Ads 10-21 扩至 26 个国家/地区、10-26 上线多图广告——agent 答案从纯 earned 竞争进入 earned + paid 双轨，H8 由此提出
5. **信任基础设施缺口收窄但未闭合**：x402 治理中立化（57 家会员、执行董事就位），但真实商业结算仅 5.1M 笔/月、身份验证缺口（Cloudflare Wallets）未决；OpenA2A 等跨平台身份草案开始填补——M4-RQ4 研究窗口继续打开
6. **国内首次出现渠道级定价**：豆包独立费率 9%–18%（住宿 12% vs 8%）+ 抖店单列 GMV/ROI——H7（AI 导购复制 CPS 佣金模型）由弱信号升级为可核算事实
