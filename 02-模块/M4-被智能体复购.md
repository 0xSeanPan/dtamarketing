# M4 被智能体复购（Repurchase & Trust）

> 状态：进行中（Phase 2 第二优先；协议情报已入库，信任基础设施图谱初建） ｜ 最后更新：2026-11-07 ｜ 总纲：`../01-总纲/研究框架.md`

## 1. 定义

智能体（及其委托人）与目标实体形成重复交易关系。人类营销对标是复购率与忠诚度体系（CRM、会员、品牌粘性），但驱动机制不同：机器忠诚度不来自情感与习惯，而来自履约记录、价格稳定性、信任评分与组织记忆——agent 每次交易都在更新它对你的贝叶斯信念。

领域现状：Stripe 已上线机器支付支持并公开了第一代智能体商务的工程经验（含失败模式）[2026-08][A] stripe.com/blog/10-lessons；x402 提供了 agent 原生支付轨道；agent 身份与真实性认证（验证"这个 agent 是谁授权的"）成为新议题。复购研究因此天然横跨交易协议与信任基础设施两块。

## 2. 研究问题

- M4-RQ1：机器忠诚度的构成因子与权重——履约成功率、SLA、价格波动、争议处理、新品供给、信任评分？哪一项的边际影响最大？
- M4-RQ2：agent 时代的"供应商锁定"形态——白名单配置、组织记忆、私有履约数据、协议绑定？锁定发生在委托人层还是 agent 层？
- M4-RQ3：负面事件（一次失败履约、一条差评）在 agent 渠道的放大系数——它进入哪些语料与评分，需要多少正向记录才能对冲？
- M4-RQ4：信任基础设施现状——agent 身份认证、可验证交易记录、信誉网络（谁在给 agent 或商家记账）？参与门槛与先发优势？
- M4-RQ5：订阅制、协议化自动续费、按量结算在 agent 渠道的适配性——agent 的"预算授权"机制如何影响消费节奏？
- M4-RQ6：跨周期问题：委托人更换 agent 平台时，供应商关系是否随交易记录迁移？这决定复购资产到底沉淀在哪。

## 3. 方法与实验协议（草案）

案例解剖：选取已公开的 ACP/UCP 商家案例（Etsy、URBN 等）与 Stripe 工程复盘，提取复购相关的设计决策与失败模式，形成案例卡片。

履约信号建模：在 M3 的调用实验上叠加履约变量（模拟成功率 95%/99%、延迟波动、价格变化），观察重复调用概率的变化曲线，估计各因子的边际效应。

语料对冲实验：向受控语料注入一条负面评价，测量它对 M1 识别与 M2 引用的影响随时间与对冲内容量的衰减。

## 4. 指标体系

| 指标 | 定义 | 采集方式 |
|---|---|---|
| 重复调用率 | 同一 agent/委托人 30 日内二次调用占比 | 服务端日志 |
| 履约分 | 成功率、时延达标率、争议率的合成分 | 交易数据 |
| 信任评分变动 | 平台或第三方信任体系中的分值变化 | 平台数据 |
| 负面冲击半衰期 | 负面事件后指标恢复至基线 50% 所需时间 | 实验 |
| 白名单进入率 | 被委托人写入常驻供应商清单的比例 | 抽样访谈/公开案例 |

## 5. 当前结论

- [2026-09][B] HUMAN Security（2026-07）：agent 浏览器会话分布——Perplexity Comet 占 47.13%、Claude in Chrome 24%、Atlas 15.5%、ChatGPT Agent 6.1%；76% 的 agent 活动命中产品与搜索路由——"agent 作为购物访客"已成为可测量的常规流量形态
- [2026-11][B] x402 治理中立化成立、商业规模证伪（口径修正，见 `协议追踪.md`）：基金会会员 57 家、执行董事就位，中立治理是复购基础设施的长期信号；但 2026-10 单月仅 5.1M 笔 / 约 $27.4 万，累计 196M 笔中过半来自 2025 年末 PING 代币刷量——**"机器支付已规模化"的判断撤回**，真实商业结算仍处早期
- [2026-09][A] UCP v2026-08-25 内置 3DS2 支付安全与结构化购物约束——信任层正被内建进协议本体而非外挂（M4-RQ4）
- [2026-09][A] Adobe：AI 访客转化率比非 AI 访客高 42%（2026-03，详见 M2 结论区）——AI 渠道客户质量溢价，复购侧含义：agent 引荐流量质量高于渠道均值
- [2026-10][B] Cloudflare Wallets（x402 生态）：为 AI 智能体提供稳定币余额与 cloudflare.pay 标识，但标识认领无域名验证机制、已引发品牌冒用与信任争议——agent 身份真实性缺口实案，M4-RQ4（信任基础设施）研究窗口打开（详见 `协议追踪.md`）
- [2026-11][A] Adobe 9 月读数（2026-10-29）：AI 访客转化率比非 AI 高 90%（连续第 12 个月上升，2025-08 时为低 9%）、单次访问收入高 83%——AI 渠道客户质量溢价继续扩大，复购侧"agent 引荐 = 高意向流量"基准更新
- [2026-11][B] Agent 身份与信任基础设施起步：OpenA2A 发布 Agent Identity Protocol 与 Agent Trust Protocol 草案（2026-09，含可验证行为信任分、可携带签名凭证、Merkle 日志吊销）；IETF 侧出现 `draft-fane-opena2a-aip-01` 与 `draft-klrc-aiagent-auth-03`——信任层正从"平台内认证"走向"跨平台可验证身份"，M4-RQ4 的方案图谱初具（覆盖 MCP 授权、Claude 托管认证、x402 钱包标识、OpenA2A）
- [2026-11][B] 机器支付双轨并行：x402（Linux Foundation 治理、57 家会员）与 Visa/Stripe/OpenAI 多协议网关（Visa Intelligent Commerce Connect）并存，Stripe 另有 Tempo 合作的 Machine Payments Protocol（会话式计费）——支付轨道中立化降低供应商锁定，M4-RQ2 观察项：锁定将从"协议绑定"转向"履约记录与信任评分"

## 6. 与商业化的连接

M4 回答的是"这门生意有没有复利"。若复购主要由履约与信任资产驱动，则服务质量工程与信任基础设施参与是长线投资；若跨平台迁移成立，则应把客户关系设计沉淀在自有可迁移层而非单一平台。对应 `../03-商业化/技能储备地图.md` 技能域 S5、S6，`../03-商业化/业务机会矩阵.md` 机会 A5、A6。
