# 研究方法与模板

> 用法：新研究开始前查阅本页，保证全库产出可比、可复现、可引用。

## 证据分级

| 等级 | 定义 | 示例 |
|---|---|---|
| A | 官方一手材料，或自己设计并可复现的实验结果 | Stripe 官方博客；M1 盲测数据 |
| B | 可验证的第三方研究、可复核的数据 | arxiv 论文；厂商研究报告 |
| C | 行业观点、轶事、单一案例 | 社区讨论；新闻转述 |

规则：C 级证据只能用于提出假设，不能支撑结论；结论升级需要 A 或 B 级证据替换。所有结论标注格式：`[YYYY-MM-DD][等级] 来源或实验编号`。

## 结论生命周期

```
假设（总纲 H 列表）
  → 验证（模块实验/文献）
  → 结论（写入对应模块"当前结论"，带证据标记）
  → 业务化（触发机会矩阵评分或决策看板）
  → 过期（平台/协议变化时改写或删除原条目，日志留一行索引）
```

## 研究笔记模板（新专题使用）

```markdown
# 专题：〔标题〕（编号：Tn）
- 起始：YYYY-MM-DD ｜ 关联模块：M? ｜ 关联假设：H?
## 问题
## 方法（数据来源、样本、时间窗）
## 证据（每条带 [日期][等级]）
## 结论（可直接被引用的一句话 + 适用边界）
## 对业务的影响（机会矩阵/技能地图/决策看板哪一项要动）
```

## 盲测协议模板（M1 使用，冻结后存 `../02-模块/盲测协议.md`）

```markdown
# 盲测协议 v〔n〕（冻结日期）
## 样本实体与入选理由
## Prompt 集（固定 20 问：是什么/能力/价格/差异/风险 各维度）
## 执行参数（模型清单、温度、是否联网、轮次间隔）
## 评分表（类目正确性/能力清单/价格/幻觉数/差异点，各 0–2 分）
## 记录方式（原文粘贴 + 得分表，存本目录 data/ 子目录）
```

## 面板测试记录规范（M2 使用）

每月一轮。记录粒度：平台 × 问题 × 答案原文要点 × 提及实体 × 引用 URL 列表 × 吸收判定（内容是否进入答案正文）。首轮之后的每轮与上轮对比，只登记变化项。数据表存 `../02-模块/` 下 `data/` 子目录，文件名 `面板-YYYYMM.csv`。

## 月度综述模板（每月最后一周，30–60 分钟）

```markdown
# 月度综述 YYYY-MM
- 本月证据更新（引用模块结论，不复制内容）
- 假设状态变化（验证/推翻/新增）
- 机会矩阵与技能地图是否需要动
- 下月优先级（不超过 3 项）
```

## 引用与链接规范

- 库内互引用相对路径链接，不复制对方正文
- 外部来源记录"来源名 + URL（如有）+ 访问日期"，URL 失效时保留来源名并标注
- 数字型结论必须能溯源到数据文件或外部 URL，做不到的降级为定性描述
